# Agents: read SPEC.md first

- The spec is `SPEC.md`. The visual reference is `prototype/index.html` + `docs/prototype/*.png`.
- Build/run/screenshot with `scripts/rb`, `scripts/shot`, `scripts/watchshot`, `scripts/video` (Mac mini 2 does the work).
- Stay inside your area (SPEC §7). Shared files: additive changes only, and list them in your report.
- Secrets: only through `vault-run` script templates with `<agent-vault:...>` placeholders. Never print, log, commit or hard-code a key.
- No chat messages, no `git push`.
